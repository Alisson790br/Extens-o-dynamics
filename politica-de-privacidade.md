## 2. Sobre a Extensão

A extensão **Dynamics Ocorrências** é uma ferramenta para uso interno que facilita o registro e acompanhamento de ocorrências no sistema Microsoft Dynamics, operando exclusivamente no contexto do navegador do usuário.

## 3. Dados Coletados

A extensão **não coleta, armazena, transmite ou compartilha** nenhum dado pessoal dos usuários com servidores externos ou terceiros.

Todas as operações realizadas pela extensão acontecem localmente no navegador do usuário.

## 4. Permissões Utilizadas

A extensão pode solicitar permissões de acesso a abas e ao conteúdo de páginas específicas do sistema Dynamics. Essas permissões são utilizadas **exclusivamente** para:

- Ler e preencher campos no sistema Dynamics
- Facilitar o registro de ocorrências na página ativa

Nenhuma dessas informações é enviada para fora do navegador do usuário.

## 5. Armazenamento Local

A extensão pode utilizar o armazenamento local do navegador (`chrome.storage`) apenas para salvar preferências e configurações do próprio usuário, sem qualquer sincronização com servidores externos.

## 6. Compartilhamento de Dados

Não há compartilhamento de dados com terceiros sob nenhuma circunstância.

## 7. Segurança

Levamos a segurança dos dados a sério. Como nenhum dado é transmitido externamente, o risco de exposição é mínimo.

## 8. Alterações nesta Política

Eventuais atualizações nesta política serão publicadas neste mesmo documento. Recomendamos verificar periodicamente.
